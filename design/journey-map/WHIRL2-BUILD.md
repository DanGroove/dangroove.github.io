## What changed

- stars.mjs: starsReserveSky now considers coast identities only. It never removes a trail dot or sea sparkle from the trip.
- stars.mjs: a seeded supply planner prepares faint sky identities before their first draw. Standalone additions exist from the start. Joined additions have fade=true, never read a fictitious hero index, and fade in place over handoffT 0.7 to 1. They retain the sky's camera-follow behavior and stay still under pointer look until the rush.
- stars.mjs: the supply covers the guaranteed source floor. An extra probe found that counting the stand-in hero's drifting sky at startup failed after a few seconds of hero dwell. Standalone supply therefore counts stable map destinations toward that floor; the moving sky still participates in the final selection. Joined sky/coast sources count toward the floor only when they remain on screen and in the same sector over the full pointer-look range. This deliberately adds more stars than a single startup snapshot's minimum.
- stars.mjs: additions are excluded from the original blast identity shuffle and use separate paint bins. During the first flash they release from the core and fade away by blastT 0.04; they contribute nothing to the later blast, remnant or reduced-motion draw. The original burst/remnant identities and random values remain unchanged.
- data.mjs: added STARS.supply only: seed 173, alpha 0.4, radius 0.65 CSS px, margin 0.04, fade [0.7, 1], out 0.04. No NOVA change was needed: its sector targets were already 14/8. Removing the new supply line restores the exact starting data.mjs SHA-256.
- The existing tail width remains 0.7 CSS px after the canvas DPR transform. The added stars' radius, alpha and tail calculations are identical at DPR 1 and 2.6; the existing DPR cap remains 2.
- Both dist HTML files and joined.html were written only by node tools/pack.mjs and node tools/pack-joined.mjs. joined.html's generated bytes are unchanged.

No trip.mjs, depth.mjs, CSS, card, find, asset, reference, hero-copy, brief or previous build-report edit was made. No git, installation, network access or browser launch was used. No server was left running.
